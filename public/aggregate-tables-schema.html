This document provides the complete, authoritative field dictionary and schema specification for the 5 database tables powering Synergy5M's Collective Buying and Demand Pooling business. It details all column data types, constraints, nullability, default values, and commercial business logic.
⚡ Platform Fee Architecture & Compulsory Rules MANDATORY
Platform Fee is compulsory across the entire aggregate business flow:
  • Product Setup (Admin): Under [CollectiveProducts] (in ProductJson.opportunity.commercial), Platform Fee % is strictly compulsory: successFeeDomesticPercent (for Domestic) and successFeeImportPercent (for Import). Products cannot be published without setting the platform fee.
  • Vendor Quotations: In [SupplyOfffertbl], the vendor-submitted platform fee is calculated and captured in the OtherCharges column (stored as total currency amount, supported by per-unit or percentage calculation).
  • Buyer Enquiries: In [CollectiveEnquiries], buyers register demand with the mandatory Region column (Domestic / International) to match with the corresponding platform fee tier.
1. [dbo].[CollectiveProducts] 15 Columns
Role: Master Collective Catalog
Stores all products opened by Admin for collective volume pooling (e.g. PVC Resin, DOP, polymers). Holds opening/closing windows, MOQ thresholds, and the compulsory Platform Fee configuration.
Column Name Data Type Constraints Description & Business Logic
Id PK NVARCHAR(100) NOT NULL Unique Product Identifier (e.g., PROD-1793180043375). Primary key.
ProductName NVARCHAR(255) NOT NULL Display product name (e.g., PVC Resin, DOP Plasticizer, HDPE Granules).
Category NVARCHAR(100) NOT NULL Industry category (e.g. Polymers, Solvents, Specialty Chemicals).
GradeVariant NVARCHAR(150) NULL Specific grade, K-value, purity, or molecular variant (e.g. K-67).
Sku NVARCHAR(100) NULL Stock Keeping Unit or internal inventory tracking code.
HsnCode NVARCHAR(50) NULL Harmonized System of Nomenclature code for tax compliance (e.g. 39041090).
Status NVARCHAR(50) DEFAULT 'Open for Enquiries' Round status: Upcoming, Open for Enquiries, Closing Soon, Closed.
Uom NVARCHAR(50) DEFAULT 'MT' Unit of measurement (MT, KG, etc.). Default: Metric Tonnes (MT).
MinEnquiryQuantity DECIMAL(18,2) DEFAULT 1 Minimum volume threshold a buyer must request to participate in this round.
MaxEnquiryQuantity DECIMAL(18,2) NULL Maximum volume limit per individual buyer enquiry.
EnquiryOpeningDate DATE NULL Date on which the demand pooling round officially opens to buyers.
EnquiryClosingDate DATE NOT NULL Hard deadline for buyers to register their volume demand.
ProductJson PLATFORM FEE NVARCHAR(MAX) NOT NULL Stores full JSON specifications, sourcing options, and compulsory Platform Fee % (commercial.successFeeDomesticPercent, successFeeImportPercent, feeNotes).
CreatedAt DATETIME DEFAULT GETDATE() Timestamp when product record was created.
UpdatedAt DATETIME DEFAULT GETDATE() Timestamp when product specifications or status were last updated.
2. [dbo].[CollectiveEnquiries] 15 Columns
Role: Buyer Demand Registration
Stores buyer registered purchase requirements. Demand from multiple buyers is aggregated by product to negotiate high-volume discounts with primary producers.
Column Name Data Type Constraints Description & Business Logic
Id PK INT IDENTITY(1,1) Unique auto-incrementing enquiry identifier. Primary key.
ProductId NVARCHAR(100) NULL Foreign reference to CollectiveProducts.Id.
ProductName NVARCHAR(255) NULL Denormalized product name for fast search and admin display.
CompanyName NVARCHAR(255) NOT NULL Buyer legal entity or company name.
ContactPerson NVARCHAR(255) NULL Name of authorized purchasing manager or representative.
Email NVARCHAR(255) NOT NULL Business email. Receives confirmation email and allocation quotation.
Phone NVARCHAR(50) NOT NULL Contact mobile or telephone number (validated 10-15 digits).
RequiredQuantity DECIMAL(18,2) NOT NULL Quantity required by buyer (e.g. 50.00). Must be greater than 0.
Uom NVARCHAR(50) DEFAULT 'MT' Unit of measure for required volume.
DeliveryLocation NVARCHAR(255) NULL Buyer plant / destination city or state (e.g. Pune, Bhiwandi, Vapi).
Region NVARCHAR(100) DEFAULT 'Domestic' Sourcing region preference: Domestic or International.
TargetDeliveryDate DATE NULL Expected date by which the buyer requires material on-site.
Comments NVARCHAR(MAX) NULL Special instructions, technical specifications, or packaging requirements.
Status NVARCHAR(50) DEFAULT 'Submitted' Status: Submitted, Under Review, Allocated, Fulfilled.
CreatedAt DATETIME DEFAULT GETDATE() Submission timestamp.
3. [dbo].[SentSupplyOffers] 17 Columns
Role: Vendor RFQ Dispatch Tracking
Maintains records of formal RFQ invitations dispatched to verified manufacturers/vendors for the aggregated demand volume.
Column Name Data Type Constraints Description & Business Logic
Id PK INT IDENTITY(1,1) Unique auto-increment RFQ dispatch record ID.
RfqReference NVARCHAR(100) NOT NULL Unique tracking RFQ code (e.g. RFQ-CB-1793560290).
OpportunityId NVARCHAR(100) NULL Collective buying round opportunity code.
VendorId INT NULL Foreign reference to Potential_Vendor.Vendor_Id.
VendorName NVARCHAR(255) NOT NULL Name of manufacturer or vendor invited to quote.
VendorEmail NVARCHAR(255) NOT NULL Recipient email address for the RFQ broadcast.
ProductName NVARCHAR(255) NOT NULL Requested product name.
Category NVARCHAR(255) NULL Product category.
Grade NVARCHAR(255) NULL Material grade requested.
TotalDemand DECIMAL(18,2) NOT NULL Total aggregated volume pooled from all participating buyers.
Uom NVARCHAR(50) NULL Unit of measurement (MT).
Destination NVARCHAR(255) NULL Primary delivery destination cluster.
BuyerEnquiriesCount INT NULL Number of buyer demand entries pooled in this round.
SubmitOfferUrl NVARCHAR(MAX) NOT NULL Secure, tokenized URL sent to vendor to submit their formal quotation.
Status NVARCHAR(50) NULL Status: SENT, VIEWED, QUOTED, COMPLETED.
SentAt DATETIME NULL Timestamp when RFQ email was dispatched.
CreatedAt DATETIME NULL Record creation timestamp.
4. [dbo].[SupplyOfffertbl] 50 Columns
Role: Vendor Quotations & Supply Allocation
Complete commercial quotations submitted by suppliers in response to aggregated RFQs. Contains pricing, taxes, logistics, lead times, allocation schedules, and Platform Fee (OtherCharges).
Column Name Data Type Constraints Description & Business Logic
Id PK INT IDENTITY(1,1) Quotation entry identifier. Primary key.
OfferReference NVARCHAR(100) NOT NULL Unique offer code (e.g. OFFER-CB-1793560395).
RfqReference NVARCHAR(100) NOT NULL References SentSupplyOffers.RfqReference.
OpportunityId NVARCHAR(100) NULL Demand opportunity ID.
VendorQuotationNo NVARCHAR(100) NOT NULL Vendor's internal quote / proforma invoice reference number.
QuotationDate DATE NOT NULL Date of vendor quote issuance.
QuotationValidUntil DATE NOT NULL Quotation validity expiration date.
VendorName NVARCHAR(255) NOT NULL Supplier company name.
ContactPerson NVARCHAR(255) NOT NULL Vendor authorized representative.
VendorEmail NVARCHAR(255) NOT NULL Vendor contact email.
MobileNumber NVARCHAR(50) NOT NULL Vendor phone number.
ProductName NVARCHAR(255) NOT NULL Offered product name.
Category NVARCHAR(255) NULL Product category.
Grade NVARCHAR(255) NULL Material grade.
TotalRequiredDemand DECIMAL(18,2) NOT NULL Target demand volume requested in RFQ.
Uom NVARCHAR(50) NOT NULL Unit of measurement (MT).
Destination NVARCHAR(255) NULL Delivery destination location.
CanSupplyFull BIT NOT NULL 1 if vendor can supply 100% of the pooled demand; 0 if partial supply.
OfferedQuantity DECIMAL(18,2) NOT NULL Volume quantity vendor commits to supply (in MT).
Moq DECIMAL(18,2) NOT NULL Minimum Order Quantity per consignment.
MaxSupplyCapacity DECIMAL(18,2) NULL Vendor's monthly or total production capacity limit.
ProductAvailability NVARCHAR(100) NOT NULL Ready Stock, Production Lead Time, or In-Transit.
PackagingType NVARCHAR(255) NULL Packaging form (e.g. 25kg PP bags, 1000kg Jumbo Bags, ISO Tanker).
OfferedUnitPrice DECIMAL(18,2) NOT NULL Base quotation unit price per MT.
Currency NVARCHAR(20) NOT NULL Quotation currency (INR, USD, etc.).
PriceBasis NVARCHAR(100) NOT NULL Incoterm: FOR Destination, Ex-Works, CIF Port.
GstRate NVARCHAR(50) NOT NULL Applicable GST percentage (e.g. 18%, 12%, 5%).
GstAmount DECIMAL(18,2) NOT NULL Calculated GST indirect tax amount in quotation currency.
FreightIncluded BIT NOT NULL 1 if freight is included in unit rate; 0 if freight is extra.
FreightCharges DECIMAL(18,2) NOT NULL Total freight logistics charges (0 if freight included).
OtherCharges PLATFORM FEE DECIMAL(18,2) NOT NULL Platform Fee amount (calculated based on per-unit, percentage, or lump-sum selection). Compulsory for all submitted quotations.
TotalBasicAmount DECIMAL(18,2) NOT NULL Basic material value (OfferedQuantity × OfferedUnitPrice).
EstimatedTotalValue DECIMAL(18,2) NOT NULL Grand total quotation value (Basic + Freight + Platform Fee + GST).
DeliveryLeadTimeDays INT NULL Lead time in calendar days from purchase order confirmation to dispatch.
ExpectedDispatchDate DATE NULL Promised factory dispatch date.
ExpectedDeliveryDate DATE NULL Promised arrival date at buyer plant destination.
DeliverySchedule NVARCHAR(100) NOT NULL Immediate (Single Lot) or Staggered (Partial Consignments).
TransportationResponsibility NVARCHAR(100) NOT NULL Supplier Arranged or Buyer Self-Arranged.
PaymentTerms NVARCHAR(255) NOT NULL Terms (e.g. 100% Advance, 20% Advance + Net 30, LC at Sight).
AdvancePaymentPercentage DECIMAL(18,2) NULL Percentage of order value required as upfront deposit.
CreditPeriodDays INT NULL Credit window in days (e.g. 15, 30, 45, 60 days).
EnquiryAllocationsJson NVARCHAR(MAX) NULL JSON array mapping vendor supply allocations to individual buyer enquiries.
StaggeredScheduleJson NVARCHAR(MAX) NULL JSON array with consignment dates and partial quantities.
AttachmentsJson NVARCHAR(MAX) NULL Metadata of uploaded proforma invoices, COA, or spec sheets.
CommercialRemarks NVARCHAR(MAX) NULL Vendor notes regarding price validity, price escalations, or cash discounts.
SpecialConditions NVARCHAR(MAX) NULL Storage requirements, offloading norms, or packaging covenants.
DeclarationConfirmed BIT NOT NULL Vendor confirmation of legal authorization and price commitment (1 = True).
Status NVARCHAR(50) NOT NULL Quotation status: Quotation Received, Allocated, Rejected.
CreatedAt DATETIME2 NOT NULL Submission timestamp with millisecond precision.
UpdatedAt DATETIME2 NOT NULL Last update timestamp.
